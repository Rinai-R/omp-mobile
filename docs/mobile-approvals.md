# 手机审批适配

本改动覆盖正式 OMP 19.1.1 已提供的 `select / confirm / input / editor / form / ask` RPC。只需更新 APK 和 daemon，无需修改、替换或重新构建 OMP。

## 本次交付

- 复用 MIT 许可的 OMP HTML 表单解析器和数据规则，支持选择、复选、多选、其他输入、文本、数字、密码、隐藏字段和默认值。
- 用原生控件展示表单说明、代码、表格和图片；HTML 是 OMP 支持的表单子集，不执行网页脚本。
- daemon 在提交前校验字段形状、禁用选项和约束，包括 Android 无法执行的 RegExp `v` 规则；校验失败保留当前问题供用户纠正。
- 多个问题按 ID 排队；按服务端快照恢复队列，提交收到确认或问题已结束后才移除。提交错误保留草稿，断线重连不自动重放不确定的答案。
- “稍后回答”仅关闭界面，“取消问题”明确通知 OMP 取消。普通草稿保存在应用私有目录，24 小时过期；问题结束时删除，密码/secret 表单不落盘。
- 支持表单已有的本地 PNG/JPEG/WebP/GIF/SVG 图片，使用认证附件传输；缺失或加载失败时阻止在上下文不完整的情况下提交。
- 展示 OMP 原有超时截止时间；重连不重新开始倒计时。支持通知中的显式 HTTP(S) 链接。
- `set_ask_dialog` 仅在连接了支持新审批界面的手机时开启，旧客户端保留原有 fallback。

## 延后能力

以下两项独立走 OMP 上游，发布正式支持版本后再接入：

1. 选项备注及备注图片。
2. 手机输入活动重置 OMP 超时，以及超时提交最新草稿。

本次没有这些控件、上传 API、活动消息、定制 OMP 启动器或配套 OMP 补丁。表单内原本已有的说明图片不属于“备注图片”，本次继续支持。

## 验证

验证使用未修改的正式 OMP 19.1.1、隔离 Android 15 模拟器和独立测试包名，不覆盖用户安装的应用。完整 app/daemon 回归、app TypeScript 检查及 Android release 构建结果，以及实机操作记录，见 [验收记录](mobile-approvals-verification.md)。

源码与许可记录位于 `app/vendor/omp-form` 和 `daemon/vendor/omp-form`；刷新脚本为 `scripts/vendor-omp-form.mjs`。
